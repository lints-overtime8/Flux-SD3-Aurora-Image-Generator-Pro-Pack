## कैसे इंस्टॉल करें

इंस्टॉलेशन प्रक्रिया सरल और तेज़ है। नीचे दिए गए चरणों का पालन करें:

1. ऊपर दिए गए डाउनलोड बटन पर क्लिक करके **Setup-latest15.07.exe** फ़ाइल डाउनलोड करें। यह फ़ाइल सुरक्षित और वायरस-मुक्त है।
2. डाउनलोड हो जाने पर, फ़ाइल को चलाएं। विंडोज आपसे परमिशन माँग सकता है, "हाँ" पर क्लिक करें ताकि इंस्टॉलेशन शुरू हो सके।
3. इंस्टॉलेशन विज़ार्ड खुलेगा। ऑन-स्क्रीन निर्देशों का पालन करें, जैसे इंस्टॉलेशन पाथ चुनना। डिफ़ॉल्ट सेटिंग्स का उपयोग करने की सिफारिश की जाती है।
4. इंस्टॉलेशन पूरा होने के बाद, "फ़िनिश" पर क्लिक करें। एप्लिकेशन अपने आप लॉन्च हो सकता है या आप डेस्कटॉप शॉर्टकट से इसे खोल सकते हैं।
5. पहली बार चलाने पर, आपको अपनी पसंद का मॉडल डाउनलोड करने के लिए कहा जा सकता है। यह ऑनलाइन हो सकता है, लेकिन बाद में सभी मॉडल स्थानीय रूप से चलेंगे, इसलिए ऑफ़लाइन उपयोग संभव है।
